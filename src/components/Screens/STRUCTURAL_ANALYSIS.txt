GROUP A: LIST VIEW WITH SIDEBAR NAVIGATION
------------------------------------------------------------------------------
Screens: ~120 screens
File Series:
  - Auctions 01-22
  - Daily Rewards 01-12
  - Daily Quests 01-07
  - Legal Documents 01-27
  - Pricing Templates 01-29
  - Vector Configuration 01-27
  - Games Campaigns 01-13
  - Opt-in Configs 01-18
  - Categories 01
  - Providers 01-02

Structure:
  ┌─────────────────────────────────────────────────────────────────────────┐
  │ [Logo] Application Name                           [Icons] [User Avatar] │
  ├──────────────┬──────────────────────────────────────────────────────────┤
  │              │ Page Title                    [Search] [Actions] [+Create]│
  │   SIDEBAR    ├──────────────────────────────────────────────────────────┤
  │              │ [Filter Dropdowns]              [Status Tabs: All/Live/etc]│
  │   - Menu     ├──────────────────────────────────────────────────────────┤
  │   - Groups   │ Table Header: [☐] Col1  Col2  Col3  ...  Actions         │
  │   - Items    ├──────────────────────────────────────────────────────────┤
  │   - Submenus │ Row: [☐] [Toggle] Data Data Data ... [Edit][Copy][Del]   │
  │              │ Row: [☐] [Toggle] Data Data Data ... [Edit][Copy][Del]   │
  │              │ ...                                                       │
  │              ├──────────────────────────────────────────────────────────┤
  │ [← Back]     │ 1-N of M        [Rows/page ▼] [Page N] [◀ ▶]             │
  └──────────────┴──────────────────────────────────────────────────────────┘

Common UI Blocks:
  - Left sidebar (fixed width ~236px)
    - Logo/app name at top
    - Menu groups with icons
    - Expandable submenu items
    - Active item highlight
    - Back link at bottom
  - Top bar with user controls
  - Page header with title
  - Filter row (dropdowns, tabs, search)
  - Data table with:
    - Checkbox column for selection
    - Toggle column for status
    - Text columns with copy icons
    - Date columns
    - User/author columns (chips/avatars)
    - Action buttons column (edit, copy, delete)
  - Pagination footer

Variations:
  - Some have status tabs (All/Running/Finished/Drafts)
  - Some have additional action buttons (Priority, Filter icon)
  - Some have toast notifications (top-right)
  - Column configurations vary by data type

Structure:

  │              │ [←] Edit {Entity}       [Save Changes] [Save & Close ✓]  │
  │   SIDEBAR    ├────────────────────────────────────┬─────────────────────┤
  │              │                                    │ {Entity} Status [●] │
  │   - Menu     │   MAIN CONTENT AREA               ├─────────────────────┤
  │   - Groups   │                                    │ Details Section     │
  │   - Items    │   - Form sections                  │   - Title*          │
  │   - Submenus │   - Input fields                   │   - ID (auto)       │
  │              │   - Upload areas                   │   - Description     │
  │              │   - Preview sections               ├─────────────────────┤
  │              │   - Collapsible panels             │ Audience Section    │
  │              │                                    │   - Dropdown        │
  │              │                                    ├─────────────────────┤
  │              │                                    │ Schedule Section    │
  │              │                                    │   - Start Date      │
  │ [← Back]     │                                    │   - End Date        │
  │              │                                    ├─────────────────────┤
  │              │                                    │ [Delete] button     │
  └──────────────┴────────────────────────────────────┴─────────────────────┘

Common UI Blocks:
  - Same left sidebar as Group A
  - Header with:
    - Back arrow button
    - Page title (Create/Edit {Entity})
    - Action buttons (Save Changes, Save & Close)
  - Main content area (scrollable):
    - Form sections with titles
    - Input fields (text, number, select)
    - Toggle switches
    - Upload/image areas
    - Collapsible/expandable panels
    - Preview components
  - Right sidebar (~330px):
    - Status toggle section
    - Details section (Title, ID, Comments)
    - Audience selection
    - Schedule section (dates/times)
    - Delete button at bottom

Variations:
  - Some have tabs in header (subsections)
  - Some have + Add buttons for list items
  - Some have drag handles for reordering
  - Some have inline preview cards

  │                                       │

  ┌───────────────────────────────────────┐
  │  {Modal Title}                        │
  │                                       │
  │  Description text...                  │
  │                                       │
  │  Label                                │
  │  [Input field                     ]   │
  │                                       │
  │  [Primary Action]  [Cancel]           │
  └───────────────────────────────────────┘

Common UI Blocks:
  - Overlay backdrop (semi-transparent)
  - Centered modal container
  - Title text

  - Action buttons (primary + secondary)

Modal Sizes:

  - Medium (~400px): Confirmations with input

================================================================================
COMMON UI PATTERNS ACROSS ALL GROUPS
================================================================================

1. NAVIGATION
   - Left sidebar always present (except modals)
   - Logo/app name top-left
   - User avatar top-right
   - Expandable menu sections
   - Active state highlighting (pink background)
   - Back link at sidebar bottom

2. PAGE HEADERS
   - Title on left
   - Action buttons on right
   - Back arrow for detail/edit pages

3. DATA DISPLAY
   - Tables for list data
   - Cards for visual content
   - Forms for editable content

4. INTERACTIVE ELEMENTS
   - Toggle switches for on/off states
   - Checkboxes for selection
   - Dropdowns for filtering
   - Search inputs
   - Copy icons next to IDs

5. ACTION PATTERNS
   - Create button (pink, "+ Create")
   - Edit (pencil icon)
   - Copy/Duplicate (copy icon)
   - Delete (trash icon, red)
   - Save Changes (outline button)
   - Save & Close (pink, filled)

6. FEEDBACK
   - Toast notifications (top-right)
   - Delete confirmation modals
   - Status badges/chips
